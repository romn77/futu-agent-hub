# Portfolio Analyst v0.8.0 实施与验收

日期：2026-10-14。基线 `a50e3e1`，开发分支 `codex/portfolio-v080-research`。
依据仓库 PRD 修订 6 和 T1–T8 计划实施；任务状态见根目录 `tasks/todo.md`。

## 已实现的用户行为

- 根据问题选择经营财务、盈利预期修订、论点检验、财报前、财报后或估值方法。
- 同一宿主使用已有相关 skills；已加载内容及合格证据复用，缺数据时同口径 Futu
  优先、其他已有授权来源补缺。没有可选 skill 仍可继续原有分析。
- 默认全部持仓基础覆盖、最多八个深入研究名称、最多两个自动完整估值；明确请求可扩围。
- 重要事实保留必要来源、期间与单位；精确估值实际计算，缺失值、错配期间或无效假设
  限制受影响结果，不制造精确目标价。
- 一份组合报告连接经营论点、反证、共同驱动和持仓风险，保留原账户快照及组件状态。
- 服务级权限拒绝对整轮同一受限能力生效，不通过更换股票重复探测。
- 单次获取后只检查同一次保留结果，不为重新展示、筛选或格式化输出再次读取账户。

生产变更集中在 `SKILL.md` 与 references。按需 Futu 能力参考独立成
`references/futu-public-research.md`。没有新增公共研究适配器、服务、默认依赖或交易能力。
入口、包元数据和运行时版本均为 0.8.0；账户 schema 不随本次产品版本机械变更。

Futu `get_financials_statements.py` 对公开 US.AAPL 的读取及一次有间隔重试均返回
`Network interruption.`，故不宣称本机 Futu 财务接口接通。两个回执分别在
`/private/tmp/portfolio-v080-public-smoke-01`、`-02`。

已有授权网页渠道成功读取 [Apple 官方披露](https://www.apple.com/newsroom/2026/07/apple-reports-third-quarter-results/)
及其 [SEC 附件](https://www.sec.gov/Archives/edgar/data/320193/000032019326000018/a8-kex991q3202606272026.htm)，
使用 futuapi 财报方法的适用部分，实际计算增速/利润率并关联本地合成仓位。
记录在 `/private/tmp/portfolio-v080-public-smoke-web-01`。这是开发者操作的公开链路检查，
不能冒充完整真实账户分析或自主模型使用真实金融服务的全流程认证。

后续只读诊断确认：SDK 与 OpenD 均为 10.10.7008，本地端口与握手正常，但
`qot_logined=false`、`trd_logined=false`，普通行情快照也快速返回 Network interruption。
因此尚未恢复上游登录/连接，不能把 doctor 握手成功解释为实际取数就绪；尚未区分登录
失效、掉线或网络问题。用户明确表示稍后处理登录，并授权先提交已验收代码。

本次未读取真实账户，没有全局安装、推送或发布。回滚只需回退本轮 analyst 指令、
评测器及版本变更；不要回滚另一路账户/交易改动。本次研究协作不要求账户数据迁移。
