Check model suitability and match security, accounting basis, currency and fiscal
period before calculating. A P/E case multiplies the matching per-share EPS by
each multiple; show the base and sensitivity and, if quoted, price comparison.
Execute the calculation and retain its output. Keep TTM, FY1, FY2 and NTM separate.
For FCFF use WACC and bridge enterprise to equity value with cash/debt and shares;
for FCFE use cost of equity. Missing debt is not debt zero. A Gordon terminal
value requires discount rate greater than terminal growth. Restrict unsupported
values while completing supported methods and other companies.
