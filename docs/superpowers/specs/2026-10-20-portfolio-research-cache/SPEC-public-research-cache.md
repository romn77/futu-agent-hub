# 公共研究缓存 Spec

模块：`public-research-cache`。状态：待评审，未实现。依赖 `cache-core`；通用字段、状态、存储与并发按[总 Spec](SPEC.md)。覆盖产品需求 R01、R02、R03、R06、R08、R09、R10、R11、R12、R13、R14。

## 1 目标

跨 session 复用来源可核验的公开资料、行情与研究摘要。固定文件不重复采集，同口径行情可共享，新申报或事件出现后只更新受影响研究。缓存不得改变公开事实的期间、单位、完整性和知识截止语义。

公共只描述数据内容，不代表任何人可读。此模块不读取账户、NAV、仓位、成本、账户偏好或私人报告。

## 2 类型与复用身份

| 类型 | 复用身份的必要字段 | 不能忽略的差异 |
|---|---|---|
| SEC 发现目录 | CIK、forms、查询期间/窗口、来源/版本、覆盖与分页状态 | 新 accession、修订、未穷尽分页、历史截止 |
| SEC 原文/章节 | CIK、accession、附件/章节、原文内容与 parser 版本、取得范围 | 章节切片不等于全文；未读附件不算已覆盖 |
| 财务事实 | 来源 accession 集合、concept/维度、期间、单位/币种、会计与修订口径 | 单季/累计、存量/期间值、GAAP/调整后、重述 |
| 13F 证据 | manager CIK、accession、report_period、修订链、单位、规范化版本 | 原申报与修订、通知、管理人重叠及覆盖缺口 |
| 行情序列 | provider/版本、完整证券身份、周期、复权、时段、日期覆盖、字段、修订依据 | 同 ticker 不同市场、前/后复权、日/周、未完成 bar |
| 动态研究资料 | provider/接口版本、公开查询、数据集、语义窗口/目标期间、口径、覆盖 | 最新新闻和历史新闻、不同预测期间、价格日期 |
| 研究摘要 | 问题/范围、证据内容摘要、发现 generation、方法/提示规则及计算版本 | 不同问题、反证变化、来源版本或适用期间变化 |

固定记录按内容寻址；查询引用选择仍有效的具体版本。动态窗口用“最近 30 日”等语义窗口与实际覆盖共同判断，不将每次运行的 now 字符串简单拼成新键；历史显式期间与截止仍必须精确核验。

## 3 SEC 目录和文件更新

目录初始 TTL 3,600 秒，从真实成功检查时间计。新请求在有效期内且允许 bounded freshness 时可使用原目录并显示其实际检查时间；要求 latest、已知新披露或目录覆盖不足时提前查源。

目录刷新结果与原列表按 accession、披露元数据和修订关系比较：

1. 集合与语义元数据不变：只更新检查回执和有效期，generation 不变，不重新下载已有正文或生成未受影响的摘要。
2. 新文档/修订：新增对应不可变证据；按实际依赖更新财务、有效 13F 持仓、研究摘要和报告。
3. 截断/失败：保留旧合格固定文档，但不能宣称新截止日的完整发现成功；相关当前研究按范围降级。

目录未变不是正文永久不变的证明。同 accession 内容如果经源核验发生变化，生成新 content_hash 并使旧衍生结果失效；不能覆盖原文出处。改变 parser 版本时可从合格原始载荷重新解析，无需把再次解析算成再次下载。

读取正文分页前先查询完整文本或有覆盖证据的片段集合。已缓存全文的 offset/limit 请求在本地切片，保留原章节定位；只取得一页时不能声明全文缓存。冷读取可在现有 SDK Reader 生命周期中连续取得需要范围，避免每一页另起 Reader 重读整段正文；首版至少保证已缓存片段在下一进程不重复读取。

知识截止沿用既有 SEC 可得性规则：新截止日需要对应发现证据；旧历史研究只消费当时已公开版本。固定文档可持续复用，目录证明的覆盖截至何时必须单独显示。不能简单修改旧 bundle 的 cutoff。

## 4 机构增量采集

先规范化用户配置的机构集合和目标季度，查询各管理人所需目录；将所需 accession 与已有合格证据作差集，仅采集缺失或变化的申报。

增量结果仍需重新验证通知、修订链、单位、管理人关系与披露完整性，再生成新的完整采集清单，使用既有分析函数计算。旧证据的 retrieved_at 不变，新清单记录这次 discovery_checked_at、目标期间和截止；不得修改原始回执来伪造采集。

`universe_version` 只是成员关系版本。计算和报告还必须匹配完整配置修订、strategy/classification/enrichment 版本、季度、知识截止和方法。名单增减、禁用、关系变化不得误复用原汇总结果；未变化管理人的原文仍可复用。

`analyze --bundle` 的现有严格校验继续生效。缓存组装后的新 bundle 必须拥有足够的本次发现证据，才可使用新的 cutoff；如果只回放原 bundle，则沿用原 cutoff。

## 5 行情共享

缓存位置在受审计来源读取的外部包装层，限定到已支持的公开行情命令。账户 `get_portfolio` 不允许经过公共缓存。来源信任版本变化必须参与键和校验，不能通过命中绕过已失效的来源兼容性要求。

风险和技术路径可共用同来源、同证券、同周期/复权/时段的原始 OHLCV。风险需要的收盘序列在本地裁剪；技术需要的其他字段必须在缓存中真实存在。超集复用须证明日期和字段覆盖、分页完整、重复/缺失处理及修订版本一致，不能仅凭“缓存里有这个 ticker”命中。

初始策略：

- 已完成交易周期的历史序列以现有市场收盘/日历逻辑确定截止，不能按操作系统自然日截断。保持完整、同口径时可跨请求复用。
- 在新交易周期、已知公司行动/数据修订时刷新相关范围。缺少可靠修订推送时，完整历史序列初始每 24 小时重新核验一次作为保守上限；这项重核验可能仍需源请求，不宣称永久不再取数。
- 尚未结束的周线或其他未封口 bar 必须明确标记，不能按“历史周线”长期冻结；按源有效期刷新，当前用途不超过 300 秒。
- 修改复权基准可能改变整段历史，不能只拼接新的一根 K 线；不确定时重取必要范围。
- 快照刷新后，已有日/周线原始证据可复用，绑定 snapshot_id 的技术或风险结果由账户模块重新判断。

行情缺失、异常日期、未知字段与零值沿用既有验证；缓存只保存被声明覆盖和核验的部分，不补零、不制造额外历史。

## 6 摘要与发现依赖

每份 `ResearchSummary` 至少包含：明确问题、对象和适用期间、事实、推断、情景、支持/反对证据引用、已执行计算及输入、缺口、需要复查的条件、方法和生成版本。

摘要拆成可独立复用的问题成果，例如“已披露季度现金转换”和“当前估值争议”。前者可以主要依赖固定财务版本，后者还依赖价格、预期等短期数据；不把整家公司所有研究强绑到一条最短 TTL 上。

用于当前观点的摘要应包含其所需的发现依赖（如新申报、重大事件），防止只验证旧文档存在就忽略新反证。有效目录重新检查且 generation 不变时，可重新确认摘要适用而不重新生成；原生成时间仍保留。相关 generation 变化后，重新评估事实与论点，不只替换引用编号。

读取顺序：先摘要和依赖元数据；合格时仅按需要展开关键引用；没有摘要或问题不兼容时再读必要原文。不能为了“验证摘要”默认把全部原文再次送入模型。哈希只能证明内容一致，不能证明来源真实或论点成立。

公共摘要写入必须从公开证据输入构建，采用字段白名单和业务检查；不得直接把含账户上下文的最终组合段落归入公共区。无法确定是否混入私人内容时，不发布到公共区，可保留为私有请求产物。文本扫描不能独自证明无泄漏。

## 7 宿主与适配契约

每次公共研究步骤：形成规范化请求 → lookup → 校验命中范围 → 缺项时 reserve → 通过现有授权工具取数 → 验证回执、来源和范围 → publish → 返回证据引用。摘要执行相同的查询与发布规则，生成步骤由宿主完成。

同一会话已加载的 Skill 内容无需因为查询缓存而重读。缓存管理不新增任意 provider registry、shell 执行或账户访问，不扩展既有八个持仓研究/两个估值等预算。

首版必要接入：analyst 的历史 K 线、SEC helper 的发现/正文/财务/13F 证据、公司与机构研究摘要，以及组合宿主对这些产物的消费。通用 web/MCP 可通过显式回执登记接入；没有实际 lookup/publish 路径的来源标记 `NOT_INTEGRATED`，不计入覆盖。相同输入在两次宿主调用中的实际效果需有工具回执验证。

SEC 在 miss 时保留现有只读 SDK、身份配置、临时环境、预算和来源限制；不以简单打开 SDK HTTP cache 代替本 Spec。跨进程协作按核心租约，来源请求预算按实际可控范围计量。

## 8 接入位置、测试与成功标准

拟修改 analyst 的 `price_history.py`、`technical.py` 与对应 provider 创建位置；公共缓存适配层位于 `portfolio_analyst/cache/`。SEC 的 Reader/CLI 接入可选缓存协议；公司与机构的 SKILL/workflow 及共享 evidence/tools 说明同步更新。未启用可选缓存时原命令行为保持可用。

通用结构、命令、代码风格和范围控制继承[总 Spec](SPEC.md)。拟议定向验证命令，实施后从 analyst Skill 目录执行：

```bash
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -m pytest tests/test_cache_public.py tests/test_cache_summaries.py -q -p no:cacheprovider
```

同时运行 SEC 完整离线回归，以及历史行情/技术原有回归。使用固定合成 accession 与可计数来源，验证独立进程正文分页、目录无变化、新修订、知识截止、13F 仅补缺项、行情超集/口径不匹配、摘要反证和宿主实际调用。

成功标准为对应验收项通过，正文/行情重复获取和摘要场景的原文输入实际减少；仅生成磁盘文件、命中内存字典或显示“cache hit”不算完成。
