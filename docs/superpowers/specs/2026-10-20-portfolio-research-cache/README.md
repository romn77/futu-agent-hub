日期：2026-10-20。状态：PRD 与技术 Spec 草案；缓存尚未实现。用户已同意分层复用方向与时间场景，本目录将其整理成可评审的产品要求和实现契约，不代表下面的具体接口已经上线或完成验收。

## 能力划分

| 稳定模块 ID | 责任 | 依赖 |
|---|---|---|
| `cache-core` | 私有文件存储、条目有效性、依赖解析、失效、租约与诊断 | 现有 Python 标准库及本地安全目录能力 |
| `public-research-cache` | 公开原始证据、发现目录、行情、研究摘要及来源适配 | `cache-core`；既有授权取数能力 |
| `account-analysis-cache` | 账户范围解析、短期快照与绑定计算结果 | `cache-core`；行情可复用 `public-research-cache`；既有账户 helper |
| `report-cache` | 规范化请求、完整报告命中与部分复用编排 | 上述三个模块；宿主研究工作流 |

依赖顺序为 `cache-core → public-research-cache → account-analysis-cache → report-cache`。公共研究不读取私有账户；报告只引用下层产物，不反向成为下层事实来源。核心存储是三层共用能力，不增加一个面向用户的研究产品。

交付检查点延续前面讨论：先公共证据和研究摘要，再短期账户与计算结果，最后完整报告。原子存储与最小并发保护从核心阶段就必须存在，不能等到最后才保证数据正确性。本目录不替代后续实现任务计划。

## 已确认范围与工程默认值

- 默认复用同一用户、本机的合格缓存，包含短期账户数据；每次正常分析不重复询问是否缓存。
- 当前组合分析使用短期账户快照；日终复盘绑定明确的交易日和快照时点，不把一天前的账户资产当成盘中当前值。
- SEC 按申报版本复用原文，按发现目录检查更新；新文档或修订只影响相关研究。
- 账户有效期 300 秒、SEC 目录 3,600 秒、新闻发现 900 秒、动态预期与估值资料最多 86,400 秒，均为可调整的初始上限；具体来源更严格的限制优先。
- 本地缓存容量初始为公共区 512 MiB、私有区 128 MiB；私有缓存最多保留 24 小时，提前容量淘汰允许发生。有效期、保留期和历史归档独立。
- TTL 到期只改变可用性；下一次请求才触发必要更新。此次范围不包含后台调度、推送、远程共享或跨用户复用。
