# Spec Portfolio Analyst 接入

模块：`portfolio-integration`。状态：设计草案。依赖[共享 SEC 证据](SPEC-sec-evidence.md)，可消费公司研究与机构调研结果。

## 1. 目标

在现有账户事实、研究预算和输出结构内，提高关键判断的原始证据质量，并让机构风格线索帮助确定研究优先级。接入后的默认持仓分析仍是一份完整组合报告，不变成三份报告拼接。

## 2. 不变的账户与预算合同

- 每次新综合诊断使用一次 fresh REAL/USD snapshot；所有账户事实绑定同一 snapshot_id/as_of。
- 使用现有 helper 的 risk、technical，只有持有期权才运行 options。不得为 EDGAR 重跑 helper、技术分析或采集第二份账户。
- NAV、数量、成本、现金和账户权重只取现有账户证据。公司现金不能填补账户现金；研究价格不刷新快照权重。
- 所有非零已成交持仓完整覆盖。默认最多八个持仓深研、两套完整估值；请求候选时默认至多两家非持仓公司及一项策略，继续使用现有政策。
- 普通组合诊断不自动运行整个机构池，也不因机构信号而自动开启新增候选、历史记录、模拟或保存。
- 不修改账户 adapter、risk／technical／options 引擎或现有生产 schemas，不向 `scripts/portfolio.py` 新增 research 命令。

## 3. 路由与触发

| 场景 | 行为 |
|---|---|
| 普通持仓分析 | 保持默认账户流程；在已选公司研究中按缺口使用 SEC |
| “结合机构配置变化” | 使用本轮已有合格信号；没有时在用户配置机构池范围运行机构调研，账户仍只采一次 |
| “研究这家公司”且未要求组合影响 | 转独立公司研究，不把持仓账户当必需输入 |
| “从调仓中找机会” | 机构调研输出研究线索；有进一步深研／建议意图时才进入对应路线 |
| 同会话先完成独立研究，再分析组合 | 复用合格公开事实；本次账户仍需 fresh snapshot，历史研究不能替代当前账户 |

机构调研或公司研究结果缺失时，analyst 继续原有分析，限制受影响判断，不把可选扩展失败当作账户失败。

## 4. 六条研究路线中的 SEC 分工

| 现有路线 | SEC 证据 | 仍需其他来源／方法 |
|---|---|---|
| 财务与经营 | 报表、业务分部、现金流、附注 | 当前经营背景及必要行业数据 |
| 预期修正 | 对照管理层披露及历史实际 | 同期分析师预测与修正记录 |
| 论点验证 | 业务、风险、资本配置、前后申报变化 | 竞争／行业证据、必要反证 |
| 财报前瞻 | 前期实际及此前已公开指引 | 已确认日期、真正的事前共识 |
| 财报回顾 | 实际结果、解释、已公开指引 | 事前预期、市场反应 |
| 估值 | 可比历史财务输入 | 价格、预测、折现／倍数假设及执行计算 |

修改现有“补缺口优先 Futu”表述为按事实域选择：已有合格证据优先复用；账户和行情遵循现有来源；申报事实和正文优先发行人／SEC；市场预期选择相应合格来源。不得为了比较而无差别同时拉取多套相同数据。

## 5. 机构信号如何影响 analyst

1. 接收带 cutoff、report_period、样本版本、覆盖与出处的公开 `StyleSignal`／`ResearchLead`。
2. 在本地将公开公司／行业主题与本次持仓匹配。主题关联权重只表示持仓关联，不能称为精确收入暴露、资金流或相关系数。
3. 在原有选择规则中，将信号作为研究优先级的补充理由。用户点名与原有重大风险优先，机构信号不能悄悄挤掉应覆盖对象。
4. 对受影响公司核验经营与估值，判断机构变化是否与公司事实一致。公开季度末持仓线索不能直接证明当前市场已转向。
5. 有充分证据时给出组合意义；证据不足时输出具体复核问题，而非把信号自动映射为 ADD／TRIM。

只选择与本次组合有关的重点信号，默认最多三条。机构报告中的候选列表不会自动继承为 analyst 的候选建议，仍受用户意图与候选预算约束。

## 6. 时间、复用与格式

账户 as_of、研究 cutoff、公司报告期间、13F 季末和披露时间分别标明。若本次研究 cutoff 晚于已有研究结果，复用不可变原始文件，但先检查结论依赖的后续事件／新申报；有新证据时只补取差量。

沿用 [output-contract.md](../../../../Futu%20API%20Skills/portfolio-analyst/references/output-contract.md) 的既定章节顺序：

- `重点研究`：公司原始证据、实质反证、机构背景及影响。
- `观察`：相关风格线索、组合复核条件、已授权候选或建议。
- `宏观影响`：只有存在实际宏观传导证据时才引用；机构持仓变化本身不是宏观事实。
- `数据缺口与来源`：机构池覆盖、报告滞后、缺失分类或文件等实质限制。

不新增强制顶层“13F 全报告”章节，不改变完整持仓表字段，不把非持仓对象放入持仓表，不输出原始 JSON。

## 8. 验证命令与成功条件

现有可执行的纯测试命令（仓库根目录）：

```bash
cd "Futu API Skills/portfolio-analyst"
.venv/bin/python -m pytest tests/test_prompt_architecture.py tests/test_prompt_loading.py tests/test_report_sections.py tests/test_current_analysis_helper.py -q
```

以上命令用于实现后受影响合同的回归，本次文档编写不声称已执行。新增行为评测应核实宿主 trace，不能仅依靠模型自述“只采集一次”。

成功条件见 [PORT-01 至 PORT-06](ACCEPTANCE.md#6-portfolio-analyst-接入)。已有研究规则的字面测试若需调整，应保持其语义不变并新增行为证据，不以删除失败断言的方式接受回归。

## 9. 边界

始终：只读、单快照、原有预算、原有格式、公开最小查询、局部降级。

后续明确范围才开展：持久配置变更、定时任务、模拟或保存结果。用户已明确授权的具体操作按既有会话授权执行，无需按接口反复确认。

永不在本流程执行：下单、解锁交易、以机构信号自动调整账户、将私人组合上传给公开研究工具。
