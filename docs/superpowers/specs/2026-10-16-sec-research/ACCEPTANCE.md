# SEC 研究体系验收规范

状态：V1 验收基线。以下为要求；实际运行结果、范围及限制见[实现记录](../../../../Futu%20API%20Skills/sec-research-core/docs/implementation.md)。模块索引见[总设计](README.md)。

## 1. 验证层次

| 层次 | 验证内容 | 证据 |
|---|---|---|
| 确定性单元／契约 | 期间、单位、修订、完整性、证券映射、分母、信号数学 | pytest 与逐项可核对 expected values |
| 固定公开样例 | 已人工核对的申报、附件、封面和摘要 | 精确 accession、来源 URL、输入版本、原始与规范化数据 |
| 只读集成 | 当前已配置 MCP／SDK 是否能提供所需资料 | 实际工具回执、解释器／版本、读取范围与缺口 |
| 行为评测 | 研究反证、路由、预算、公开请求、账户隔离及报告内容 | 宿主执行 trace 和报告证据定位，不能只看模型自述 |
| 现有 analyst 回归 | 单快照、所有持仓、NAV、格式、风险／技术／期权边界 | 现有测试及新增行为场景 |

单元测试离线；真实账户不是公司研究／机构调研测试前提。公开实时读取用于验证能力，不把网络波动误判为纯计算错误，也不把模拟结果声称为真实读取成功。

## 2. 共享证据

| ID | 场景 | 必须满足 |
|---|---|---|
| SEC-01 | 文件定位后再次读取 | 所有章节绑定同一 accession；latest 变化不漂移到新文件 |
| SEC-02 | MD&A 被服务端或宿主截断 | 标记截断，关键结论补读或收窄；不得写“已通读全文” |
| SEC-03 | 四条季度记录混有累计数／期间缺口 | 不直接求 TTM；只有可核验的独立四季才计算 |
| SEC-04 | 截止后修订／财报／分类资料 | 历史可得性视图排除；只有日期时不声称精确盘中可得 |
| SEC-05 | null、真零、不同币种／单位 | 状态不混淆；未验证单位不算精确指标 |
| SEC-06 | ticker 对应不同股类／ADR、CIK 歧义 | 不错误合并；需要的身份映射缺失时局部降级 |
| SEC-07 | 同一事实在两个流程使用 | 复用合格原始证据，保留来源／口径，说明必要补取 |
| SEC-08 | 返回正文含指令、SDK 写入、权限拒绝 | 正文不扩大权限；真实文件效应可说明；拒绝不经替代路径绕过 |

## 3. 独立公司研究

| ID | 场景 | 必须满足 |
|---|---|---|
| CMP-01 | 无 OpenD／账户环境，用户只问公司 | 不执行 doctor／snapshot；公开研究正常运行或局部降级 |
| CMP-02 | 主要论点遭遇实际相反证据 | 修改判断／置信程度或明确解释为何不推翻；不能忽略 |
| CMP-03 | 外国发行人只提供 20-F／6-K | 按实际披露研究；没有 10-Q 不等于没有财务数据 |
| CMP-04 | 缺少实时价格／历史共识 | 不伪造预期差／目标价；经营判断可继续 |
| CMP-05 | 13F 线索引出公司研究 | 机构行为是研究动机，不代替经营证据；未完成验证明确标记 |

## 4. 机构配置与风格调研

| ID | 场景 | 必须满足 |
|---|---|---|
| INST-01 | 空名单、禁用项、重复 CIK、同名多实体 | 不自动补机构；不重复计票；歧义明确处理 |
| INST-02 | 不同机构最新报告属于不同季度 | 固定 target_period，不混合 latest；未报告者为缺失 |
| INST-03 | top-20 返回，但原始报告有 100 行 | 不用前 20 行作全量分母或判断其余仓位退出 |
| INST-04 | 原始 → RESTATEMENT → NEW HOLDINGS | 完整替换后再增补，保留来源；重复读取不重复计数 |
| INST-05 | 补充披露首次公开但报告期较早 | 归属历史期；不解释为当前新买；截止前不可提前使用 |
| INST-06 | 金额单位美元／千美元、SDK 已归一化 | 不二次乘 1,000；对账失败或单位歧义阻止金额信号 |
| INST-07 | 同 CUSIP 的股、期权及 PRN，不同股类 | 不混合数量／方向；主普通股范围排除不适用行并披露 |
| INST-08 | 股票拆分／证券标识改变 | 已核验纯拆股不形成假增持；不明重组为不可比 |
| INST-09 | 数量不变、股价上涨 | 原始权重可变；同价重估配置变化为零 |
| INST-10 | 所有持仓同比例增加 | 报告数量增加，配置比例不变；不称特定风格偏好增强 |
| INST-11 | 缺失、保密、组合报告、13F-NT | 不当成空仓／退出；不可比较者不进分母 |
| INST-12 | 母子管理人或其他管理人重复覆盖 | 不制造多个独立支持票；不明关系披露并限制共识 |
| INST-13 | 用户名单跨运行改变 | 使用共同样本或重算同名单历史，样本变化独立说明 |
| INST-14 | 不同相邻期使用不同可用机构集合 | 不拼成同一样本持续趋势；持续性基于固定共同集合 |
| INST-15 | 无合格风格／历史分类数据 | 不编造成长／价值结论；可继续已核实行业观察 |
| INST-16 | 只有两家机构／覆盖不足／正反分歧 | 输出观察，不硬凑五条线索；不给未经验证的概率或买卖信号 |
| INST-17 | 退出证券缺少本期参考价格 | 不令价格为零；排除并报告两期覆盖／分母变化 |
| INST-18 | 请求超过下载／时间预算 | 保留实际完成、未完成及原因；不静默删机构或截持仓后报全量 |

## 5. 必须包含的数值样例

以下均为合成数据，不是实际基金／公司事实。计算必须由程序执行，预期值由独立算术核对。

| 样例 | 输入 | 预期结果 |
|---|---|---|
| 价格漂移 | A/B 各 100 股；旧价格均 10，新价格 A=20、B=10；股数不变 | A 普通权重从 50% 到 66.6667%；两者同价重估配置变化均 0 |
| 纯拆股 | A 前期 100 股、金额 1,000；2:1 拆股后 200 股、金额 1,000 | 调整 q0*=200；delta_q=0；无主动增加线索 |
| 配置迁移 | A/B 原各 100 股；当前各价 10；本期 A=150、B=50 | A 同价重估变化 +25 个百分点，B 为 -25 个百分点 |
| 同比例增加 | A/B 原各 100 股，本期各 120 股；价格及相对结构不变 | 两者数量 +20%；配置变化均 0，不标特定主题偏好 |
| 市值分解 | q0=100,p0=10；q1=120,p1=15 | 市值增 800；数量变化代理 300，重估变化 500；不称真实流入 300 |
| 修订链 | 原 A=100,B=50；重述 A=90,B=60；增补 C=20 | 有效 A=90,B=60,C=20，不保留被替代旧数量 |
| 跨机构广度 | 五个独立可比机构 d=+3%、+2%、+1%、-1%、0 | 增 3、减 1、平 1；net_breadth=0.4；median_shift=100 bps |
| 覆盖门槛 | 八个启用独立机构，仅六个可比 | 覆盖率 75%，低于默认 80%，仍可报告事实但不升级研究线索 |
| 样本不足 | 五个启用机构，仅四个可比 | 虽覆盖 80%，仍未满足至少五个独立可比机构 |
| 退出价格缺失 | 前期有 A，本期无 A，且没有合格本期价格 | 可在完整披露条件下标不再报告；固定价格权重不默认 p1=0 |

另需零分母、负数异常、同一期重复行、金额舍入差、主题标签重叠、分类变化导致的假轮动等错误／边界样例。

## 6. Portfolio Analyst 接入

| ID | 场景 | 必须满足 |
|---|---|---|
| PORT-01 | 综合分析同时触发 SEC 取证 | fresh helper 只调用一次；账户证据绑定一致；不重跑 technical |
| PORT-02 | 机构信号涉及未持有证券 | 不放入完整持仓表；候选意图／预算不满足则只作研究线索 |
| PORT-03 | EDGAR 失败／部分报告缺失 | 局部降级，保留原有账户与其他可靠分析 |
| PORT-04 | 已完成公司研究后请求组合判断 | 复用合格公开证据；fresh 账户不能由历史研报替代 |
| PORT-05 | 请求发往公开研究服务 | 无账户 ID、snapshot ID、权重、数量、NAV、私人路径／备注和组合清单 |
| PORT-06 | 报告汇总 | 原章节、全持仓、预算、估值语义和期权边界全部保持；机构信号不自动映射交易 |

## 7. 验收执行与发布判定

先执行纯计算及输入契约测试，再核对固定申报样例，然后做有限真实读取与行为评测。每种降级路径都必须证明还能交付哪些可靠内容。

重大错误零容忍：错误归属机构／证券、未来信息泄漏、千倍单位错误、假建仓／清仓、将缺失设零、私人数据外传、重采账户。任何一项出现即阻止相应模块发布；不能用总体分数抵消。

研究质量需要检查：结论是否由实际读取内容支持；实质反证是否得到回应；风格线索是否保留样本与期间边界；输出是否给出可执行的下一步研究问题。不得用关键词命中或章节齐全替代这些判断。

默认研究线索门槛只用于选题，需在公开样例与合成边界上检查稳定性；门槛通过率不能称为收益胜率。任何收益／预测能力声明另需严格时点、交易成本、历史样本与样本外验证，超出本版。

## 8. 已知技术风险与处理

| 风险 | 处理与发布要求 |
|---|---|
| MCP 本机版本／运行实例不一致 | 记录实际运行能力；按返回数据验证；不能只靠文档版本 |
| MCP 只能取摘要／最新申报 | 使用精确 accession 的受控 SDK 读取；缺口未解决则不能发布全量机构信号 |
| 历史证券、公司行动数据不足 | 局部不可比并披露，严格限制覆盖；不强制所有历史可比 |
| 修订与共同管理关系复杂 | 无法确认的 manager-period 不进入完整聚合；给出定位与原因 |
| 分类把价格／标签迁移误判成风格偏好 | 同价重估、冻结分类、迁移分列，配套反例测试 |
| 新功能扩大 analyst 默认工作量 | 条件加载、复用、原预算；普通诊断不自动扫描机构池 |
| 其他工作同时修改 analyst 规则 | 实施前重新核对基线，在相关测试上整合；不覆盖无关工作 |
