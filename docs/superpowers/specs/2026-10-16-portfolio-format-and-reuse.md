# Portfolio report format and reference reuse

日期：2026-10-16。用户要求继续未完成任务；起点 `0b9e469`，沿当前分支开发。
依据：[上一轮 spec](2026-10-15-portfolio-report-reliability.md) 与
[锁定结果](<../../../Futu API Skills/portfolio-analyst/docs/2026-10-15-report-reliability.md>)。

## Scope and diagnosis

仅处理标准章节格式与完整参考文件重读；保留账户字段、研究质量、默认读取完整性、
生产引擎/schema、一次采集与只读边界。原始报告、评分和历史 AC-17 结论不改写。
R1 为上一轮冻结指令；R2 为本轮候选。新版本可以使用旧失败调试，不能再称旧题为留出。

回执复现：Q02 的加粗冒号标签不能定位章节；研究/输出规则均完整读取后又在采集前重读。
未见这些读取截断，不能将其解释为截断补读。三项假设按优先级验证：
1. 二级标题要求与加粗标题说明有歧义；给出可直接使用的标题写法应减少格式错误。
2. 读取顺序和重复导航促使模型重新加载研究/输出规则；将两者放到默认读取末尾并明确
   基于成功回执复用，应减少完整重读。
3. 宿主上下文丢失或压缩导致重读；若前两项修改后仍重读，不能仅凭提示词宣称已解决。

## Implementation and verification

- 在评测端单独验证精确二级标题、顺序、条件期权章节和重复/缺失；忽略代码围栏中的示例。
  保留原有宽容提取用于诊断，不将段落标签自动改成合规章节。真实负例先 RED 后 GREEN。
- 输出契约明确章节与段落标签的区别，发送前从现有上下文检查最终标题及字段。
- 默认必读文件集合不变，保留完整读取证据。调整顺序及复用动作，缺失/截断内容仍须补齐。
  不添加测试专用禁止重读提示、不改模型工具目录、不增加生产缓存或持久化。
- D0 保持不超过 6,900 词 / 54,512 字符；全量测试、Ruff、skill 校验及范围核验通过。

## Frozen evaluation

独立准备者在 R2 产品编辑前冻结三项全新合成输入及操作者量表，不接触旧答案或输出。
旧 Q02/Q05 和已观察 H01–H03 均仅作回归。最多四份旧题开发探针，用于已知失败定位，
每份保留原件；服务失败才允许有原因的重试。探针不计入最终对照，不能替代独立验收。

最终候选冻结后执行新留出 3×R1/R2×2重复=12 份，旧 Q02/Q05 各两份 R2=4 份。
模型请求 gpt-6-astra / medium，600 秒 / 8 MiB，随机预登记顺序、新进程、只读与相同
输入/runtime/工具。记录实际 CLI 和哈希；不能把未知服务端 revision 描述成固定权重。
模型输入不含版本、评分目标或答案。独立评审评分锁定后解盲，不将代理当作人类评审。

本轮目标是修复剩余行为，不改写上一轮质量改善门槛或历史 AC-17：

- 16 份全部执行/审查；不可缩分母、挑选报告、覆盖失败或为正确输出重试。
- R2 十份报告均满足精确章节、全部旧执行/字段检查，关键事实/交易/隐私错误为零。
- R2 新留出每份 F/R/C 至少 3，各案例均分降幅不超过 0.25，事实均值不下降。
- R2 完整读取满足默认/实际条件要求，首次成功后无完整重读；仍有则复用项未通过。
  另报部分补读、重复字符、实际输入/缓存/输出 token；不以词数下降推断费用节省。
- 仅在总均分严格提高、至少 2/3 案例改善且各维度均值不下降时声称本轮样本质量改善。
  质量改善与上述定向缺陷修复分别报告，不能据此把历史 AC-17 改成通过。

看到新留出输出后不再调整 R2；新问题进入下一轮回归。外部执行遵守已有授权和宿主
审批；不因审批拒绝更换服务或工具规避。所有账户数据保持纯合成，不读取真实持仓。

## Delivery

分片本地提交评测检查、产品指令及冻结样本、执行记录。完整证据留存本地忽略目录，
Git 只含源文件、合成输入和简短记录。不推送或合并，不宣称未执行的行为检查通过。
